# eXpress Reader для Codex

[English version](README.md)

Локальный доступ из Codex к корпоративной переписке eXpress в режиме только чтения.

Плагин открывает официальный веб-клиент eXpress в отдельном профиле Chrome или Edge, а адрес корпоративного сервера хранит отдельно. Ты входишь в аккаунт в самом окне браузера; плагин не запрашивает и не экспортирует пароль, одноразовые коды, cookies или access-токены.

## Модель безопасности

- Среди MCP-инструментов нет отправки сообщений, ответов, реакций, редактирования, удаления, пересылки и загрузки файлов.
- Чтение ограничено доменом настроенного веб-клиента eXpress.
- Скачивания в браузере отменяются.
- Сообщения хранятся только в памяти текущей MCP-сессии; незашифрованный локальный индекс не создаётся.
- Текст переписки считается недоверенными данными, а не инструкциями для Codex.
- При открытии чата eXpress может отметить сообщения прочитанными.

Отдельный профиль браузера и URL конфигурации по умолчанию хранятся в `%LOCALAPPDATA%\eXpressReader4Codex`. В профиле остаётся браузерная сессия eXpress, поэтому его нужно защищать так же, как любой авторизованный профиль браузера.

## Требования

- Windows 10 или 11
- Node.js 20 или новее для отдельной разработки (Codex предоставляет совместимый runtime для MCP)
- Google Chrome или Microsoft Edge
- Доступ к корпоративной веб-версии eXpress

## Подготовка проекта

```powershell
cd plugins/express-reader
pnpm install
pnpm test
pnpm run check
```

Для локальной разработки адрес корпоративного сервера можно сохранить командой:

```powershell
pnpm run configure -- https://express.example.org
```

По умолчанию используется веб-клиент `https://corp.express`. Второй URL или переменная `EXPRESS_WEB_URL` нужны только тогда, когда организация размещает отдельный веб-клиент. Корпоративный сервер можно временно переопределить через `EXPRESS_CORPORATE_SERVER_URL`.

## Первый запуск

1. Вызвать `express_configure` с `corporateServerUrl`. Веб-клиент по умолчанию — `https://corp.express`.
2. Вызвать `express_open_login`.
3. Проверить подставленный сервер, продолжить и войти в аккаунт в открывшемся отдельном окне браузера.
4. Вызвать `express_list_chats`.
5. Читать необходимые переписки через `express_read_chat`.
6. Когда нужно разобрать скриншот или фотографию из конкретного сообщения, вызвать `express_read_image`, указав чат, при необходимости тему обсуждения, текст сообщения и автора.

Адаптер намеренно не использует закрытые API eXpress. Он читает Shadow DOM через браузерный DOM-снимок и откалиброван на Web eXpress 3.72.37. Если в следующей версии изменится разметка, `express_inspect_ui` отдаст ограниченный диагностический снимок для однократной калибровки.

`express_read_chat` возвращает сообщения, загруженные самим eXpress, и по возможности прокручивает историю вверх согласно `historyPages`. Поле `loadedMessageCount` показывает фактически полученную глубину.

`express_read_image` возвращает ограниченное по размеру PNG-представление одной встроенной картинки. URL изображения, cookies, заголовки и токены наружу не передаются; произвольное скачивание файлов инструмент не поддерживает.

## Установка в Codex

Из локальной копии репозитория:

```powershell
codex plugin marketplace add .
codex plugin add express-reader@express-reader4codex
```

Либо напрямую с GitHub:

```powershell
codex plugin marketplace add kdenv2604/eXpress-reader4Codex --ref main
codex plugin add express-reader@express-reader4codex
```

После установки нужно создать новую задачу Codex, чтобы загрузились skill и MCP-инструменты плагина.

## MCP-инструменты

| Инструмент | Назначение | Изменяет данные eXpress |
| --- | --- | --- |
| `express_status` | Показывает конфигурацию и состояние браузера | Нет |
| `express_configure` | Локально сохраняет веб-клиент, корпоративный сервер и браузер | Нет |
| `express_open_login` | Открывает отдельный профиль и подставляет корпоративный сервер | Нет |
| `express_list_chats` | Читает видимые чаты и признаки непрочитанных | Нет |
| `express_list_threads` | Показывает видимые обсуждения eXpress | Нет |
| `express_read_chat` | Открывает и читает один чат | Может отметить прочитанным |
| `express_read_thread` | Открывает и читает одно обсуждение | Может отметить прочитанным |
| `express_read_image` | Возвращает одну картинку из точно указанного сообщения | Может отметить прочитанным |
| `express_close_thread` | Закрывает обсуждение и возвращает список чатов | Нет |
| `express_search_loaded` | Ищет по чатам, прочитанным в текущей сессии | Нет |
| `express_inspect_ui` | Снимает ограниченный текст интерфейса для калибровки | Нет |
| `express_close_browser` | Закрывает отдельный локальный браузер | Нет |

## Состояние проекта

Read-only MCP-сервер, отдельный постоянный профиль браузера, чаты, обсуждения, счетчики непрочитанных, структурное чтение сообщений и ограниченная выдача встроенных изображений реализованы. После будущих обновлений интерфейса eXpress адаптеру может потребоваться повторная калибровка.
